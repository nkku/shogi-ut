# 変更履歴

## 2026-11-25 — v1.0.2: 棋譜取り込み後の評価値グラフ再生成

- KIF/SFENから取り込んだ棋譜 (およびアプリ再起動後) は評価値が未記録だったため、
  評価値グラフに **「再生成」ボタン** を追加。全局面を1局面≈1.2秒で順に再検討し、
  「再生成中 34/108 …」の進捗表示つきで曲線を構築する。**中止**もいつでも可能
  (途中までの部分グラフはそのまま見られる)。
- 再生成中もグラフを開いていれば曲線がリアルタイムで伸びていく
  (evalCurveChanged → Canvas再描画 + 要約更新)。
- C++: SearchKindにSearchReplay追加 (終局済み棋譜でも走れるよう onEvalInfo の
  over_ ゲートを通過)。検討探索中に再生成を押した場合は stop→bestmove 完了から
  開始 (pendingReplayStart_)。新対局開始 (resetEvalState) で中断・状態消去。
- ツールバー「グラフ」ボタンを (曲線が空でも) 手数2以上なら有効化。
- グラフのタップ詳細に **「その手目へ」**: 盤面だけ経過ply手目まで巻き戻して閲覧できる
  (Game::gotoPly。usiMoves_・時計・终局状態は不変)。閲覧中は人間入力と対局goを発行せず、
  時計行中央が「N手目閲覧」(赤)になるのでタップで最新局面へ復帰。

## 2026-11-24 — v1.0.1: 持時間7時間化・評価値グラフの目盛追加 (ユーザー使用感フィードバック)

- 持時間の上限を 60分 → **420分 (7時間、プロ棋戦並み)** に拡張。
  120分以上はステップ30、60分以上は15に自動可変。60分以上は「N時間M分」表記を併記。
  経過表示も `H:MM:SS` 形式に対応 (420:00 のような mm:ss 暴走を防ぐ)。
- 評価値グラフに **300点刻みの目盛グリッド+数値ラベル** (0/±300/±600/±900/±1200) を追加。
  終局点をマーカーで強調し、グラフ下に「終局評価・最大先手・最大後手 (手数付き)」の要約を表示。
- グラフに**手数表示**: x軸に手数ラベル (総手数に応じて10/20/40/80手刻み)、
  グラフをタップすると赤マーカーを立てて「手数 N: 指された手(KIF風) 評価 +xx」を詳細表示。
  曲線データ (Game::evalCurve) に move キー (その位置を作った着手) を追加。
- (使用感フィードバック反映) ±900/±1200 の数値ラベルがグリッド線からズレる不具合を修正
  (テキストのベースラインを全目盛で中央揃えに統一)。
- 画面上部の時計行の中央に **「N手目」を常時表示** (着手順 = 経過手数+1)。

## 2026-11-23 — 棋譜の書き出し/読み込みを content-hub 方式へ (OpenStore自動審査対応)

- OpenStoreの手動審査は **2026-11-02 付けで新規受付が一時停止** されている (admin pinned) ため、
  自動審査で通る構成に切り替えた。click-review は apparmor の `read_path`/`write_path` を
  `security:redflag_fields` (FAIL) と判定するため、Downloads直接読み書きを廃止。
- 書き出し: KIF/SFENをアプリ専用領域 (`~/.local/share/shogi.ow/exports/`) にステージングし、
  Lomiri.Content (`ContentPeerPicker` / `ContentHandler.Destination`) で
  「ファイルマネージャに保存」等の標準ダイアログから保存先を選べるようにした。
- 読み込み: `ContentHandler.Source` のピア選択で *.kif/*.sfen を選ぶ方式に統一
  (従来のDownloads一覧リストは廃止、`Game::listKifuFiles` も削除)。
- apparmor は `policy_groups: ["audio", "content_exchange", "content_exchange_source"]` のみに。
  (content_exchange=取り込み側 / content_exchange_source=提供側 のDBus通信許可。
  gallery.ubportsと同じ構成。これが無いと `com.lomiri.content.dbus.Service` 呼びが
  apparmor DENIED になる) `clickable review` は **pass** を返す。
- 実機で書き出し (ファイルマネージャ保存)・読み込みのピア選択UIとも動作確認済み。
- **OpenStoreへ提出・公開完了**: <https://open-store.io/app/shogi.ow> (v1.0.0 arm64、自動審査pass)。

## 2026-11-23 — つようら王11mini の同梱 (CPU棋力強化)

- CPU戦の棋力不足への対策として、同梱エンジンに **つようら王11mini** を追加した。
  SFNN型評価関数 (nn.bin 7.7MB + progress.bin 1MB) で、水匠5の62MBより大幅に小さい。
  作者公称で水匠5よりR150〜200強く、スマホ向けに公開されている
  (やねうら王FANBOX 2026-10-14 全体公開記事、評価ファイルのライセンスはMIT)。
- SFNN評価ファイルを-loadできる探索部は無償配布されていなかったため、
  YaneuraOu master (9.96git) から `SFNN_ka2_4096_8_64_progress8` エディションを
  クロスビルドして同梱した。g++ではARMV8で成功
  (ARMV8_DOTPRODはg++でコンパイルエラー、clang+lldでは成功するがFP5実測で無効果。
  FP3等の旧ARM機互換も考慮しARMV8を同梱)。
- 評価ファイルは `engines/tsuyou11_eval/` にMITライセンス文書付きで同梱。
  READMEのライセンスセクションに各同梱物の帰属を明記。
- エンジン選択は3段 `[やねうら王|水匠5|つようら王11]` に拡大。
  新規インストールの既定は つようら王11 (既存設定のある端末は設定値のまま)。
- FP5実測 (スレッド4・秒読み30秒): 深さ21〜22到達 (水匠5は深さ16)。
- 水匠5・つようら王11の双方で通常対局・学習モード・秒読みの統合テストが成功。
- DESIGN.md につようら王11のビルド手順とdotprod实测結果を追記。
